# Images

Drop your hero background render here and point `heroBackgroundImage` in
`src/config/site.config.ts` at it.

- Default expected file: `dungeon-bg.jpg`
- Recommended: a wide (≈1920px+) landscape JPG/WEBP of your dungeon build.
- If this file is missing the site falls back to a dark gold-tinted gradient,
  so the page still works before you add artwork.

A brand logo (the "B&D" crest) can also live here — set `logoImage` in the
config to use it instead of the text fallback.
